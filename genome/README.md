# Reference genome inputs

Place the following files in this directory before running the BRBseq pipeline:

- `GCF_016920845.1_GAculeatus_UGA_version5_genomic.fna`
- `GCF_016920845.1_GAculeatus_UGA_version5_genomic.gtf`
- `genome_one_feature.gtf`
- `chr_beds/NC_053212.1.bed` through `chr_beds/NC_053232.1.bed`

The STAR indices (`4STAR/` and `4STAR_one_feature/`) are generated by the
pipeline and should not be downloaded or committed.
